# 当贝 H3 精简固件

**简体中文** | [English](README.en.md)

适配说明：**当贝 H3 盒子已实机刷写验证，使用正常；H3S 盒子兼容性待验证，暂不建议刷入。** 当前固件基于 H3 / RK3566 / Android 11 对应基础固件，不适用于其他型号。

## 精简内容

- 删除原厂桌面、播放器、屏保、OTA、首次设置向导、工厂测试、备份工具及部分当贝预装服务。
- 删除 HTML 查看器、声音选择器和备用拼音输入法，保留搜狗输入法、系统 WebView、蓝牙及遥控器配对功能。
- 保留原厂文件管理器、设置智能服务、最近任务界面和 Rocky 语音服务。
- 默认进入 Aerial 桌面，使用静音开机图、关闭窗口动画，首次启动默认关闭系统备份。

## 预装应用

**Aerial、BV、当贝市场、LXTV（ARM64）、影视 5.8.4（ARM64）、WebViewTV。**

## 下载与刷机

从 [Releases v1.3.0](https://github.com/lifengZero/DBBOXH3-image/releases/tag/v1.3.0) 下载固件：

```text
H3_RK3566_Android11_Aerial_MAINTENANCE_MARKET_STOCK_BOOT_ADB5555.img.gz
```

1. 解压 `.gz` 得到完整 `.img`，可用随附的 `.sha256` 文件校验。
2. 在 Windows 电脑安装瑞芯微 USB 驱动，准备 RKDevTool。
3. 通过 USB 连接盒子，按原有线刷方法进入 **Loader 模式**。
4. 在 RKDevTool 的 **“升级固件”** 中加载解压后的 IMG，执行升级。
5. 等待升级成功后重启，首次开机等待应用安装完成，再设置网络、配对遥控器。

**刷机会清除用户数据和蓝牙配对，请提前备份并保留原厂固件。不要直接刷入 `.gz`，不要当作 boot 分区镜像写入，刷写期间不要断电或拔线。**

## 遥控器配对

**同时按住遥控器的 Home 键和设置键，听到“滴”声后松手，等待配对完成。**

遥控器尚不可用时，可连接 USB 鼠标或键盘进入蓝牙设置。

## 注意

无线 ADB 持续开启，端口 `5555`，无需认证。仅在隔离可信网络使用，不要开放到公网或安装不可信应用。
